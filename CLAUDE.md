## Purpose
Local-first demonstrator: public ALOHA engineering assets → semantic knowledge graph (GraphDB) →
executable Modelica virtual twin (OpenModelica) → explained by a local, ontology-grounded copilot (Ollama).
Research question: does ontology grounding (GraphDB + GraphRAG) measurably improve LLM-assisted
generation/repair of an executable Modelica model versus deterministic and LLM-only workflows?

## Hard rules
- **Runtime AI = local Ollama only** (http://localhost:11434). No hosted inference, no cloud fallback.
  Claude Code is the development agent only; it is never called by the application.
- **Simulation results shown anywhere must come from real OpenModelica runs.** Never fabricate outputs.
- **Never invent physical parameters.** Use URDF/vendor values, label derived values, flag assumptions.
  Placeholder URDF inertials (mass ≤ 1e-3 kg, no geometry) are rendered massless and reported.
- Pinned reference assets in `third_party/` are read-only (fetched by `tools/fetch_sources.py`).
- GraphDB: only touch repository `kkh-aloha-engineering`. Never delete/modify other repositories.
- LLM tools are read-only (validated SPARQL templates, bounded read-only SPARQL, OMC check in isolated
  workspaces). Model changes proposed by the LLM require human approval before being accepted.
- Houssem's ALOHA model must never be an input to generation; comparison only after the generated model is frozen.

## Modelica generation conventions
- Prescribed motion: driven joints use `Move` sources fed by analytic q/qd/qdd (`Blocks.WaypointTrajectory`
  → `cosineBlend` function). Joints use `stateSelect=never`. Do NOT put trajectory logic in `algorithm`
  sections with Integer segment indices — OM 1.27 index reduction fails on it.
- Massless links without geometry must set `frame_a.f = 0, frame_a.t = 0` (else 6 missing equations each).
- Joint input connectors carry no `unit` attribute (mixed rad/m vectors trigger unit inconsistencies).
- URDF rpy → `FixedRotation(PlanarRotationSequence, sequence={3,2,1}, angles={yaw,pitch,roll})`.

## Experiment conventions
- Ontology rule set for candidate checking lives in `kkh/domain/aloha/candidate.py`. Rules were frozen at `53405d7`
  before the held-out mutations; if rules change, write a NEW held-out set before re-measuring.
- Inside a SPARQL `GRAPH <g> {}` clause GraphDB sees only explicit triples; put inferred patterns (e.g. `?j a kkh:Joint`) outside.
- Writing regexes through bash heredocs can turn the regex word boundary (backslash-b) into a backspace character — check files for chr(8).
